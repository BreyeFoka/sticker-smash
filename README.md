# StickerSmash

A small Expo app, built while following Expo's official tutorial: pick a photo from your library, add an emoji sticker you can drag and resize, then save the result to your device.

## Run it

```bash
npm install
npx expo start
```

Open it in Expo Go, an Android emulator, an iOS simulator or the browser.

## Checks

GitHub Actions type-checks the app and runs `expo lint` on every push.

Built with Expo Router, React Native Gesture Handler and Reanimated.
